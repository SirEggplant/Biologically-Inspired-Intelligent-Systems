# CSCI‑633: Biologically‑Inspired Intelligent Systems

A collection of programming assignments from **CSCI‑633: Biologically‑Inspired Intelligent Systems** at the Rochester Institute of Technology.  
This repository demonstrates implementations of various nature‑inspired metaheuristics for continuous optimization.

## 📁 Assignments

| Folder | Description |
|--------|-------------|
| `hw1` | Implementation of stochastic hill climbing with random restarts applied to the negative Alpine function. Analysis of the exploration‑exploitation trade‑off. |
| `hw2` | Simulated Annealing (SA) for minimizing Rosenbrock’s and Ackley’s functions. Experiments with initial temperature and step size. |
| `hw3` | Differential Evolution (DE) and Particle Swarm Optimization (PSO) applied to Rosenbrock and Easom functions. Parameter tuning and performance comparison. |
| `hw4` | Firefly Algorithm (FA) for multimodal optimization. Applied to the four‑peak and eggcrate functions. Study of population size and hyper‑parameters (γ, α, β). |

## 🚀 Getting Started

Each assignment folder contains a report pdf and the algorithms mentioned in the homework.  
All code is written in **Python 3.8+** and requires **numpy** as well.
